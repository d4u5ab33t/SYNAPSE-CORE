# SYNAPSE-CORE WONG initial scaffold

This branch contains a minimal scaffold for WONG fOS: Python package with data models, a small autopsy helper, a hypothesis competition module, a FastAPI skeleton, a JSON schema for forecasts, and a basic unit test.

Recommended stack:
- Python 3.10+
- Neo4j for Evidence Graph (neo4j-driver)
- Postgres for time/event storage (psycopg2-binary)
- FastAPI for REST API
- Background workers can be added later (Celery/RQ)
